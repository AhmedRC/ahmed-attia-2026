MULTI-AGENT PARALLEL ARCHITECTURE

الوكلاء الفرعيون والتشغيل الموازي (Sub-Agents)

يتيح النظام إطلاق عدة وكلاء مستقلين في الخلفية لتطوير وبحث المهام المعقدة بالتوازي دون حجز سياق الجلسة الرئيسية.

كتابة واختبار النماذج

invoke_subagent

مهمة توازية

إطلاق مجموعة من الوكلاء الفرعيين بالتوازي في الخلفية وتوزيع الأدوار والموجهات بشكل محدد لكل وكيل.

invoke_subagent({ Subagents: [ { TypeName: "research", Role: "Backend Auditor", Prompt: "فحص أمان خوادم API" }, { TypeName: "self", Role: "UI Engineer", Prompt: "تطوير المكونات الهيكلية" } ] })

define_subagent

تعريف وكيل

إنشاء نمط وكيل مخصص بموجهات نظام وأدوات محددة لإعادة استخدامه خلال المحادثة.

define_subagent({ name: "structural_engineer", description: "وكيل هندسي متخصص في تحليل العناصر الإنشائية", system_prompt: "أنت خبير في التصميم الإنشائي والمعايير الكودية...", enable_write_tools: true })

manage_subagents

إدارة الوكلاء

استعلام قائمة الوكلاء النشطين، أو إنهاء مهام محددة أو كافة الوكلاء العاملين.

manage_subagents({ Action: "list" // خيارات أخرى: "kill", "kill_all" })

send_message

تواصل مباشر

إرسال رسائل أو توجيهات إضافية لوكيل فرعي معين أثناء استمرار عمله في الخلفية.

send_message({ Recipient: "conversation-id-789", Message: "قم بتركيز الفحص على ملفات المخطط الإنشائي فقط" })
DIRECTOR SLASH COMMANDS

أوامر الشَرطة التفاعلية (Slash Commands)

أوامر سريعة يُدخلها المستخدم مباشرة لتفعيل أنماط وسلوكيات خبيرة ومتخصصة في Antigravity AI.

/goal

هدف مستقل

تحديد هدف شامل وطويل المدى يستمر النموذج في تنفيذه واستكشافه دون توقف حتى تحقيقه كاملاً.

/goal إجراء مراجعة شاملة لجميع اختبارات الوحدة وإصلاح الأخطاء حتى تعمل بنجاح 100%

/schedule

جدولة آليّة

جدولة مهمة دورية تكرارية أو ضبط مؤقت زمني لتنفيذ فحص أو تنبيه محدد.

/schedule تشغيل فحص المزامنة مع قواعد البيانات كل 30 دقيقة

/browser

أتمتة المتصفح

توجيه الذكاء الاصطناعي لفتح موقع ويب، التفاعل مع العناصر، واستخراج البيانات أو الصور.

/browser استخرج مستندات المكونات البرمجية والتقط صورة للصفحة الرئيسية

/grill-me

استجواب وتدقيق

بدء جلسة مقابلة تفاعلية لاستجواب فكرة مشروعك وحل حواف القرارات والتصاميم قبل التنفيذ.

/grill-me قم باستجوابي حول النظام الهندسي لتصميم المنشأ قبل البدء في كتابة الأكواد

/teamwork-preview

فريق وكلاء

توزيع مشروع ضخم على مجموعة متكاملة من الوكلاء الذكيين للعمل كفريق متناغم.

/teamwork-preview تقسيم تطوير أداة الأتمتة إلى وكيل للواجهة ووكيل للخلفية ووكيل لاختبار DXF

/learn

ذاكرة دائمة

حفظ التفضيلات أو المعايير الخاصة في الذاكرة المستمرة لاستخدامها في الجلسات القادمة.

/learn احفظ تفضيل استخدام خط Fraunces للعناوين الرئيسية ونظام ألوان Navy/Gold
PRECISION DEVELOPMENT TOOLS

أدوات التطوير والنظام (System & Coding Tools)

أدوات العمليات المباشرة على بيئة العمل، تشغيل الأوامر البرمجية، وتعديل الكود بدقة متناهية.

run_command

أوامر الطرفية

تنفيذ أوامر Terminal/Shell مباشرة محلياً مع إمكانية التشغيل في الخلفية ومتابعة المخرجات.

run_command({ CommandLine: "python3 build_architectural_plan.py", Cwd: "/Users/mac/Documents/antigravity", WaitMsBeforeAsync: 1000 })

view_file

معاينة ملف

معاينة وفحص محتويات الأكواد، الصور، المخططات، والوثائق النصية بدقة الأسطر.

view_file({ AbsolutePath: "/Users/mac/Documents/antigravity/DESIGN.md", StartLine: 1, EndLine: 60 })

write_to_file

إنشاء ملف

إنشاء ملفات جديدة أو استبدالها مع توثيق التعديلات وتجهيز البنية التحتية تلقائياً.

write_to_file({ TargetFile: "/Users/mac/Documents/antigravity/config.json", CodeContent: "{\n \"version\": \"1.0.0\"\n}", Overwrite: true, Description: "إعداد ملف التهيئة الرئيسي" })

replace_file_content

تعديل دقيق

استبدال كتلة محددة ومستهدفة من الكود البرمجي دون المساس بأصل الملف أو الأسطر المجاورة.

replace_file_content({ TargetFile: "/Users/mac/Documents/antigravity/index.html", StartLine: 15, EndLine: 20, TargetContent: "

Old Title

", ReplacementContent: "

New Title

", Description: "تحديث العنوان الرئيسي" })

grep_search

بحث برمجي

فحص واستخراج الأنماط البرمجية والمتغيرات عبر كافة ملفات المشروع بسرعة عالية.

grep_search({ SearchPath: "/Users/mac/Documents/antigravity", Query: "Fraunces", MatchPerLine: true })

generate_image

توليد الصور

إنشاء الأصول البصرية وتصاميم الواجهات البرمجية استناداً إلى وصف دقيق لاستخدامها في المشاريع.

generate_image({ Prompt: "Academic navy and gold UI dashboard design mockup", ImageName: "academic_dashboard", AspectRatio: "16:9" })
TEMPORAL AUTOMATION

الجدولة والمهام الخلفية (Scheduling & Tasks)

إدارة المؤقتات الفردية والمهام التكرارية المجدولة لمتابعة وتفحص السيرفرات والأعمال البرمجية.

schedule

مؤقت وجدول

إعداد جدول زمني Cron أو مؤقت فردي بالثواني لإرسال تنبيه أو تنفيذ عملية آلياً.

schedule({ CronExpression: "0 * * * *", Prompt: "إجراء عملية فحص صحة النظام وتدقيق السجلات كل ساعة" })

manage_task

متابعة الخلفية

متابعة وتفحص حالة الأوامر الشغالة في الخلفية، إرسال المدخلات إليها، أو إنهاؤها.

manage_task({ Action: "status", TaskId: "task-10293" })
RESEARCH & KNOWLEDGE RETRIEVAL

أدوات البحث واستخراج المعرفة (Web Search)

البحث المباشر عبر شبكة الويب وقراءة المستندات والمواقع للحصول على أدق المراجع والمعلومات.

search_web

بحث الويب

إجراء بحث شامل عبر الإنترنت واستخراج ملخصات دقيقة مدعومة بالروابط والمراجع.

search_web({ query: "ETABS API Python automation documentation" })

read_url_content

قراءة رابط

جلب محتوى صفحة ويب مباشرة وتحويلها إلى نص بتنسيق Markdown لمعالجتها.

read_url_content({ Url: "https://docs.python.org/3/" })
END-TO-END IMPLEMENTATION EXAMPLES

أمـثلة وسيناريوهات تطبيقية شاملة

نماذج عمل حقيقية تجمع بين الوكلاء الفرعيين، أوامر الطرفية، وأدوات الجدولة لتنفيذ مهام متكاملة.
